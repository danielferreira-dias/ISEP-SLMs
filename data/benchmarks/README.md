# Benchmark releases

Benchmark data is grouped by suite:

- `ISEPDermaBench/` is the Hugging Face-ready private package with rendered
  prompts, benchmark-preprocessed images, schemas, and isolated references.
- `dermobench/` contains the external gated DermoBench release.

The release manifests retain checksums for their referenced configuration and
artifacts. Use the paths recorded in each manifest rather than assuming a
release is an independent cohort.
