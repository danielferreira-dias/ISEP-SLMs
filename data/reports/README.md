# Dataset reports

These files are generated by:

```bash
.venv/bin/python -m src.data_pipeline.pipeline
```

Version 1 records the initial 13-class candidate analysis. Version 2 is the
current 20-class analysis and adds complete canonical source-label coverage.

The primary current reports are:

- `source_disease_inventory_v2.csv`: source labels, canonical labels, mapping
  status, and per-source counts;
- `all_source_disease_coverage_v2.csv`: totals for every canonical source
  label, including labels outside benchmark scope;
- `disease_coverage_v2.csv`: coverage of the 20 active benchmark classes using
  taxonomy contributors only;
- `included_diseases_v2.yaml`: the 20 classes that pass preliminary support
  thresholds;
- `out_of_scope_source_labels_v2.csv`: source labels retained for accounting
  but excluded from the benchmark taxonomy.

All counts are preliminary until duplicate analysis and final group-safe split
validation are complete.
