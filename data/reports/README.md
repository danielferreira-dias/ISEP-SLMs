# Dataset reports

These files are generated by:

```bash
.venv/bin/python -m src.data_pipeline.pipeline
```

Version 1 records the initial 13-class candidate analysis. Version 2 records
the 20-class expansion. Version 3 is the current 21-class analysis, adds
`drug_eruption`, indexes the excluded Dermnet Kaggle mirror for auditability,
and adds demographic and subgroup-support reporting.

The primary current reports are:

- `source_disease_inventory_v3.csv`: source labels, canonical labels, mapping
  status, and per-source counts;
- `all_source_disease_coverage_v3.csv`: totals for every canonical source
  label, including labels outside benchmark scope;
- `disease_coverage_v3.csv`: coverage of the 21 active benchmark classes using
  taxonomy contributors only;
- `included_diseases_v3.yaml`: the 21 classes that pass preliminary support
  thresholds;
- `out_of_scope_source_labels_v3.csv`: source labels retained for accounting
  but excluded from the benchmark taxonomy.
- `demographic_availability_v3.csv`: group-level metadata availability for all
  source rows and benchmark-mapped rows;
- `subgroup_coverage_v3.csv`: group and image support for reportable
  demographic subgroups, by dataset and disease.

The subgroup report omits non-informative values such as `unknown`,
`other_or_unspecified`, and `prefer_not_to_answer` from metric-eligible groups.
Their absence remains visible through the availability and missingness counts.
Measurement systems are not pooled.

All counts are preliminary until duplicate analysis and final group-safe split
validation are complete.
