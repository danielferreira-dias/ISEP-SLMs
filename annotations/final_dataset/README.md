# ISEPDistillDataset

Esta pasta reúne a decisão metodológica final para construir o dataset multimodal de treino da tese. O documento principal descreve a unidade de dados, as fontes elegíveis, as configurações Hugging Face, o protocolo de geração pelo teacher, os filtros de qualidade, a prevenção de leakage, o treino do student e as ablações necessárias.

1. [Plano detalhado de construção do ISEPDistillDataset](01_isep_distill_dataset_construction_plan.md)

O conteúdo desta pasta é uma especificação de implementação e experimentação. Não significa que o dataset já tenha sido gerado, revisto clinicamente ou publicado.
